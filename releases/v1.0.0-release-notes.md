# 外卖账号管理系统 v1.0.0 发布说明

我们很高兴地宣布外卖账号管理系统正式版(v1.0.0)现已发布！

## 主要功能

### 多平台账号管理
- 支持美团外卖、饿了么、京东到家等多个外卖平台
- 统一界面管理所有平台账号
- 分类显示不同平台的账号

### 账号安全管理
- 本地加密存储所有账号信息
- 使用高强度加密算法保护用户数据
- 无云端存储，数据完全保存在本地

### 独立浏览器登录
- 每个账号使用独立的浏览器窗口登录
- 保持会话状态，避免频繁登录
- 支持多账号同时在线

### 状态监控
- 实时监控账号登录状态
- 自动检测会话有效性
- 显示上次登录时间和状态

### 会话维护
- 自动维护账号登录会话
- 定期刷新以保持登录状态
- 减少手动操作需求

## 系统要求

- **操作系统**: Windows 7/10/11 或 macOS 10.14+
- **内存**: 至少4GB RAM
- **硬盘空间**: 至少200MB可用空间
- **网络**: 稳定的互联网连接
