# 版本 1.0.0 (2023-06-18)

## 变更

- 初始版本发布
- 基础账号管理功能
- 多平台支持：美团外卖、饿了么、京东外卖

## 功能

- 多平台账号管理
- 账号添加、编辑、删除功能
- 账号登录与状态刷新
- 数据加密存储

## 系统要求

- 操作系统：Windows 10/11, macOS 11+
- 存储空间：至少100MB可用空间
- 内存要求：2GB及以上

## 已知问题

- 账号登录状态刷新仅基于最后登录时间，可能不准确
- 验证码登录场景需手动操作
- 同一平台的多账号登录可能存在会话冲突

## 安装方法

1. 下载安装包
2. 解压到任意目录
3. 运行应用程序

## 卸载方法

1. 删除应用程序目录
2. 删除用户目录下的数据文件夹 (Windows: %APPDATA%\waimai, macOS: ~/Library/Application Support/waimai)
